# Kuis Rebutan Tim

- `index.html` : layar utama / operator (laptop atau proyektor). Musik lobby dan musik permainan sudah tertanam di dalam file ini.
- `play.html`  : halaman HP tiap tim (pilih tim, nama, suara, buzzer, jawaban).
- `*.mp3`      : suara buzzer tim dan efek benar/salah (9 file).

Semua file harus berada di folder yang sama (tanpa subfolder).
